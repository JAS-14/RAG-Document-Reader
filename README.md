# RAG Document Reader

A full-stack Retrieval-Augmented Generation (RAG) application that enables users to upload documents, index their contents, and ask natural language questions to receive context-aware answers generated by an LLM.

The application combines a React-based frontend with a FastAPI backend to provide an intuitive document question-answering experience.

---

## 🚀 Features

- User Authentication (Login & Signup)
- Secure JWT-based authorization
- Upload PDF documents
- Automatic document processing and indexing
- Retrieval-Augmented Generation (RAG)
- Conversational document-based question answering
- Chat history management
- Responsive Bootstrap UI
- Fast and scalable REST APIs

# 🧠 Retrieval-Augmented Generation (RAG)

The application uses Retrieval-Augmented Generation to improve answer quality by grounding LLM responses using uploaded document content.

## RAG Workflow

### 1. Document Upload

Users upload PDF documents through the frontend.

↓

### 2. Document Loading

The backend extracts text from uploaded documents.

↓

### 3. Text Chunking

Large documents are divided into smaller semantic chunks for efficient retrieval.

↓

### 4. Embedding Generation

Each chunk is converted into vector embeddings using an embedding model.

↓

### 5. Vector Storage

Embeddings are stored in a vector database for similarity search.

↓

### 6. User Query

The user submits a natural language question.

↓

### 7. Similarity Search

Relevant document chunks are retrieved based on semantic similarity.

↓

### 8. Context Injection

Retrieved chunks are added as context to the prompt.

↓

### 9. LLM Response

The language model generates an accurate answer grounded in the retrieved document context.
